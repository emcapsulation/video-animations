# Video Animations
This repo contains code for my YouTube video animations.

My channel: https://www.youtube.com/@emcapsulation

I do the animations using the Manim library but I hope to branch out one day and try Blender or other cool stuff.

I'm currently refactoring this repo to be a bit cleaner so sorry if some of the animations are broken. Also the code in this repo is not very pretty, I just sorta write whatever to get the animations I want without worrying about code quality.

```
source .venv/bin/activate
python -m manim -pqh <path to .py file> <scene name>
```
